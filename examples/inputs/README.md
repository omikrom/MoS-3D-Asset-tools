# Example inputs

Place clean reference images or existing models here before building the
example specifications. Image-to-3D references work best with:

- the entire asset visible and centred;
- a plain or transparent background;
- even studio lighting with no hard cast shadow;
- an A-pose for characters and symmetrical creatures;
- no cropped weapons, feet, horns, tails or wings;
- additional front/side/back images where the selected provider supports them.

The TOML examples intentionally remain useful as templates before their sample
images exist; `mos validate` checks structure while `mos build` checks files.
